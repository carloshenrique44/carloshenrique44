I support production SQL Server databases for electronic traffic enforcement systems, spread across
multiple servers and client contracts. My work sits between keeping routines healthy, investigating
data incidents and automating what used to be done by hand.

### 🗄️ What I work on

- **Production support** — incident investigation, root cause analysis and data fixes under change control
  (peer review, validation queries before and after, rollback plan).
- **DBA routines** — FULL/DIFF backups, integrity checks, index fragmentation analysis and maintenance,
  availability monitoring; rollout of standardized routines to new servers.
- **Automation** — SQL Server Agent jobs, Windows Task Scheduler + `sqlcmd` for SQL Server Express,
  PowerShell dashboards that consolidate routine reports from every server.
- **Data movement** — loading production data into test environments while respecting foreign keys
  and handling ID collisions, using linked servers.
- **Access and security** — read-only logins and profiles following least privilege; credentials kept out of code.
