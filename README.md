### 🗄️ DBA Toolkit

- **SQL Server:** advanced T-SQL (CTEs, window functions, explicit transactions), SQL Server Agent jobs, Database Mail, linked servers
- **Maintenance routines:** FULL/DIFF backups, integrity checks, index fragmentation analysis and rebuild, availability monitoring
- **Data operations:** loading data between environments while respecting foreign keys and ID collisions; production data fixes with peer review and rollback plan
- **Security:** read-only logins and profiles following the least privilege principle; no credentials in code
- **PostgreSQL:** telemetry queries and equipment availability analysis
- **Automation:** PowerShell monitoring dashboards, Task Scheduler + `sqlcmd` for SQL Server Express, REST API integrations
- **Versioning:** Git and GitLab; studying CI/CD pipelines for SQL change scripts
